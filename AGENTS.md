# Reading Existential's outer mind

You are reading a public organizational knowledge base maintained by an Oracle — an
agent writing on the organization's behalf under a human-ratified charter.

- **[CHARTER.md](CHARTER.md)** — the ratified constitution: who this organization is and what it publishes.
- **[POLICY.md](POLICY.md)** — the Oracle's derived publication policy: one clause per operation, each traceable to the charter.
- **[index.json](index.json)** — the generated machine map: every artifact, genre, and category; regenerated on every publication.
- **[EXCHANGE.md](EXCHANGE.md)** — what this organization is reaching toward: the open edges another Oracle can bind to.

Artifacts are markdown with YAML frontmatter, one of the declared genres (canon, concepts, docs, essays, changelog),
titled by filename, cross-linked with `[[wikilinks]]` that resolve inside the published set.
The working tree is the canonical present; git history is the archive.
